# موقع مَعْلَم الرسمي

ملف `index.html` مدمج بالكامل (يحتوي على الخط المرفق والشعارات ولقطات الشاشة داخل الملف نفسه) ليعمل مباشرة دون الحاجة لمجلدات إضافية.

## النشر على GitHub Pages
1. ارفع ملف `index.html` إلى المستودع (Repository).
2. من **Settings → Pages** اختر الفرع `main` والمجلد `/ (root)` ثم احفظ.
